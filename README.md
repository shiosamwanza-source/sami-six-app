## 📱 What Is SAMI SIX APP?

SAMI SIX APP is a **mobile-first digital trade platform** that eliminates the need for East African SMEs to physically travel abroad to source goods.

Instead of spending **$2,000–$4,000 per trip** to Guangzhou, Dubai, or Istanbul — a trader in Kariakoo opens the app, uploads a product photo, gets a verified quote, pays the product cost only, and receives their cargo at their doorstep in Dar es Salaam.

**Six Cargo and Sami Agency finance the freight, TRA customs duty, VAT, and port charges — the trader pays the balance only when their cargo safely arrives.**

## ⚡ The Problem It Solves

| # | Problem | SAMI SIX Solution |
|---|---------|-------------------|
| 1 | **$2,000–$4,000 travel costs** per sourcing trip | Source verified suppliers from your phone in Kariakoo |
| 2 | **Broker fraud** — agents with no office, no license, no collateral | SAMI Escrow System — funds held by Sami Agency, released only after cargo verified |
| 3 | **Lost cargo** — LCL agents use manual bookkeeping, cargo gets mixed or smuggled | Barcode scanning + Digital Inspection Passport on every item at Six Cargo warehouse |
| 4 | **Hidden TRA fees** — surprise customs charges after cargo arrives | Automated Tariff Engine shows exact Total Landed Cost before you pay anything |
| 5 | **No cross-border visibility** — trucks delay at DRC/Zambia border with zero tracking | SAMI FAW Haulage Fleet with IoT GPS — track your truck live to Lubumbashi or Lusaka |

## 🔄 The 11-Step Workflow

```
PHASE A — Request & Deposit
  Step 01 → Upload product photo / link / voice request
  Step 02 → Six Cargo overseas team sources the product
  Step 03 → Quotation: Product Cost (pay now) + Cargo Charges (financed)
  Step 04 → Pay PRODUCT COST ONLY into Six Cargo bank account (SAMI Escrow)

PHASE B — Verify & Approve  
  Step 05 → Admin verifies deposit, triggers overseas purchase
  Step 06 → Warehouse uploads 2 photos + 1 video → Buyer taps APPROVE

PHASE C — Finance & Ship
  Step 07 → Six Cargo finances & arranges international sea freight
  Step 08 → Sami Agency pays TRA customs duty + VAT + port charges
  Step 09 → Cargo arrives Dar es Salaam → Final invoice generated

PHASE D — Clear & Release
  Step 10 → Buyer pays logistics balance via M-Pesa / bank transfer
  Step 11 → Digital Cargo Release Pass issued → FAW delivery or collection
```

## 👥 6 User Role Dashboards

```
1. SME Buyer          → Submit requests, track orders, pay deposits & final balance
2. Supplier           → View procurement requests, submit factory pricing (USD/CNY/AED)  
3. Warehouse Staff    → Log weight/CBM, upload 2 photos + 1 validation video
4. Clearing Agent     → Log TRA customs values, push final invoice to buyer
5. Logistics/Driver   → Update delivery milestones, GPS border check-ins
6. Admin              → Verify payments, manage exchange rates, issue release passes
```

*Role-Based Access Control (RBAC) + Row-Level Security (RLS) — each role sees only their own data.*

## 🚀 Running the Prototype Locally

The prototype is a single React JSX file. To run it:

```bash
# Option 1 — Paste into Claude.ai Artifacts (easiest)
# Copy SAMI_SIX_FINAL_COMPLETE.jsx content → paste into Claude → runs instantly

# Option 2 — Run locally with Vite
npm create vite@latest sami-six-prototype -- --template react
cd sami-six-prototype
npm install
# Replace src/App.jsx with SAMI_SIX_FINAL_COMPLETE.jsx content
npm run dev
# Open http://localhost:5173
```
